ANALYSIS:
It would seem that a manual zoom and crop which both fills the entire frame of the image with a given coin as well as orients the coin correctly improves the categorization ability of the model significantly. I would attribute this largely to the fact that the images, post-manual-crop, resemble the Kaggle dataset images much more closely. 
There is however, one stipulation:
When doing a test, you are supposed to change only one variable. In this test, I changed the image size, seed, and cropping of the coins, all in one test. I did this out of convenience, as manually cropping every image in my local dataset is time-consuming. When starting with a square 512x512 pre-named dataset, it saves me a lot of time. I am still inclined to believe that the improvement in categorization accuracy came largely from the manual crop, however, as this would make logical sense. 
In order to ensure that the user of a future product using this AI would still have a hassle-free experience, I would intend to create a camera overlay for the user to fit over the coin when taking a photo, similar to how one would scan a check in an online banking app. 
I am still suspicious of the background differences between that of Kaggle and my local image dataset, and the potential for this to cause issues with categorization. 

CONCLUSION:
To investigate further, I would like to write a script to add pixels to each image in the Kaggle dataset, potentially with autogenerated noise to create a consistent background, so as to offset the location and potentially the orientation of each coin in the dataset. This in theory could force the AI to pick up to the right patterns (ie. the patterns related to the coin itself) rather that spurious correlations found in aspects like the background. 
Another possibility would be to experiment with taking photos of local dataset coins, and find a background that the model is better at categorization with. This would likely, however, translate to increasing the burden on the user further in any future product with which this AI model is deployed.
